# オークションハウス

Delta Chat のチャット内で、出品・入札・落札結果の共有ができる webxdc アプリです。

## ファイル

| ファイル名 | 内容 |
| --- | --- |
| `Auction-House-v1.1.0.xdc` | 修正版アプリ。導入時に別途用意してください |

## はじめに

1. 主催者が `Auction-House-v1.1.0.xdc` を、参加者がいる Delta Chat のチャットへ送信します。
2. 全員が、**その同じメッセージのアプリ**を開きます。
3. 名前を入力し、「決定して入室」を押します。
4. 主催者の出品を待ち、品物の内容を確認して入札します。

各自が別々に `.xdc` を送信すると、別のアプリとして扱われます。利用するアプリのメッセージを全員でそろえてください。修正版は初回にデモ商品を表示しないため、出品が0件でも正常です。

## 参加者の操作

1. 品物の一覧で「入札する」を押し、説明と価格を確認します。
2. 「次回最低入札」以上の金額を、整数で入力します。
3. 金額欄の横の「入札する」を押します。
4. 入札履歴と最高額を確認します。

例：現在価格1,000円、最低入札単位100円の場合、最初の入札は1,100円以上です。

**入札の確認画面と取り消し操作はありません。** 金額をよく確認してから押してください。終了済み、または指定の終了時刻を過ぎた品物には入札できません。

「質問する」は未実装です。質問は Delta Chat のチャットで行ってください。「ウォッチ」は画面上の目印で、再起動後の保存や端末間共有を前提にしないでください。

## 主催者の操作

### 主催者として入室する

1. 最初の入札者登録画面で名前を入力します。
2. 大きな「入札者として参加」ボタンを、初期設定では約1.5秒以内に3回タップします。
3. 「オークショニアモード」でパスワードを入力します。初期値は半角小文字の `secret` です。
4. 「入室」を押します。

主催者画面の歯車でタップ回数とパスワードを変更できますが、この版では再起動後まで保存されません。

主催者用パスワードは画面の切り替え用です。参加者の不正操作を防ぐ本人確認の仕組みではありません。信頼できる参加者同士で利用し、主催者をチャットで共有してください。

### 出品する

1. 「新規出品」にタイトルと説明を入力します。
2. 必要なら「＋」から画像を選びます。最大4枚です。
3. 開始価格を0円以上、最低入札単位を1円以上の整数で指定します。
4. 必要なら終了時間を指定し、「出品する」を押します。
5. 他の参加者にも品物が表示されたか確認します。

### 締めて落札する

1. 参加者の入札履歴がそろっているか確認します。
2. 対象の品物の最高額と入札者を確認します。
3. 「締めて落札」を押します。確認画面はありません。

入札があれば最高入札者が落札者として表示され、入札がなければ落札者なしで終了します。終了時間を指定した場合も、落札者を確定するには主催者が「締めて落札」を押す必要があります。

支払い・配送の機能はありません。受け渡し方法はチャットで相談してください。出品の編集・削除、入札や終了の取り消し操作もありません。

## 通信と保存

出品・入札・終了情報を webxdc の更新メッセージで共有します。大きなデータは分割して送信します。受信履歴と送信待ち情報は端末内に保存し、起動時に履歴を復元して送信を再開します。

画面上部の「同期・データ引き継ぎ」で状態を確認できます。

| 表示 | 意味 |
| --- | --- |
| 履歴を同期中… | 過去の更新を読み込み中 |
| 送信待ち N 件 | ホストへの引き渡し待ち。アプリを開いたまま待ってください |
| 同期受付中 · v1.1.0 | 同期を受け付けている状態 |

**送信待ちが0件でも、全端末への到着を保証するものではありません。** 締める前や移行前には、他の参加者にも履歴を確認してもらってください。画面内の「リアルタイム」という文字だけで同期完了を判断しないでください。

## バックアップと新版への引き継ぎ

### バックアップを書き出す

1. 移行前に入札を止め、参加者の履歴がそろっていることを確認します。
2. 「同期・データ引き継ぎ」を開き、送信待ちがなくなるまで待ちます。
3. 「バックアップを書き出す」を押します。
4. Delta Chat 側に用意された `Auction-House-backup-日付.json` を、保存先のチャットへ送信して保存します。
5. ファイルが残ったことを確認します。必要なら端末にも保存します。

### 新版で読み込む

1. 主催者が新しい `.xdc` をチャットへ送信し、移行先のメッセージを全員に知らせます。
2. 新版を開き、初回の履歴同期が終わるまで待ちます。
3. 「同期・データ引き継ぎ」の「バックアップを読み込む」で、保存した `.json` を選びます。
4. 選択すると読み込みと参加者への送信が始まります。送信待ちがなくなるまでアプリを開いたまま待ちます。
5. 全員が同じ新版を開き、品物・入札・落札結果がそろってから再開します。

読み込みは既存データへの追加統合で、全データの消去・置換ではありません。空の新版で読み込むと確認しやすくなります。移行作業は主催者1人がまとめて行ってください。

バックアップには出品情報、画像、入札履歴、落札結果、送信待ち情報が含まれます。入室中の役割、ウォッチ、主催者用パスワードなどの画面設定は対象外です。参加者の名前や識別情報も含むため、共有先に注意してください。

### 元の v1.0.0 からの移行

元の v1.0.0 にはバックアップ機能がありません。この形式での引き継ぎは修正版 v1.1.0 から利用できます。

元の画面にだけ残っている情報を、新版が自動取得することはできません。閉じる前に必要な内容を記録し、新版へ手作業で登録してください。すでに失われた未保存データは復元できません。

## 困ったとき

| 状況 | 確認すること |
| --- | --- |
| 他の人と品物が違う | 同じチャットの同じアプリのメッセージを開いているか確認します |
| 出品や入札が届かない | ネット接続と、チャットへ通常のメッセージを送れる状態かを確認します |
| 送信待ちが減らない | 画像は分割送信されます。閉じずに待ち、エラーが続く場合は主催者へ表示内容を伝えます |
| 入札できない | 次回最低入札以上の整数か、品物が終了していないかを確認します |
| 主催者画面に入れない | 名前を入力し、参加ボタンを素早く3回押して、初期値なら `secret` を入力します |
| バックアップを読み込めない | このアプリが書き出した対応形式の JSON か、初回同期が終わっているかを確認します。32MBを超えるファイルは読み込めません |

## v1.1.0 の主な変更点

- ホスト提供の `webxdc.js` の読み込みを追加。
- 大きな出品データの分割送信と再構成を追加。
- 受信履歴と送信待ち情報の端末保存を追加。
- 入札の二重表示を修正し、同額入札の並び順を時刻とIDで統一。
- 無効な価格や、終了済みの品物への画面上の入札を抑止。
- 永続更新を優先し、未確定のリアルタイム入札経路を無効化。
- バックアップの書き出しと読み込みを追加。
