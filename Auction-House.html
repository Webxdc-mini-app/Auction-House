オークションハウス 操作マニュアル

Delta Chat の中で、主催者が品物を出品し、参加者が金額を入力して入札するアプリです。初めて使う方が、参加からデータ引き継ぎまで進められるように説明します。

立場主な操作
参加者品物を見る、入札する、結果を確認する
主催者出品する、入札を確認する、締めて落札する

対象と画面の見方　対象は修正版 v1.1.0 です。画面例はアプリ本体をパソコンの検証用ブラウザーで表示したものです。品物と名前は説明用です。スマートフォンでは表示位置や並び方が変わることがあります。

読む順番　入札する方は2～3ページ、主催者の方は4～5ページをご覧ください。新版への引き継ぎは6～7ページ、困ったときは8ページです。

始める前の約束　全員が同じチャットに送られた、同じアプリのメッセージを開きます。各自が別々に .xdc ファイルを送ると、別のオークションになります。価格、終了のタイミング、支払いや受け渡し方法をチャットで決めておきましょう。

1 アプリを開いて参加する

主催者から届いたアプリを開き、名前を確認して入室します。

  1. 参加する Delta Chat のチャットを開き、主催者が送った Auction-House-v1.1.0.xdc を探します。
  2. そのメッセージのアプリを開くボタンを押します。ボタン名は端末によって「開始」などと表示されます。
  3. 「お名前」に、参加者に分かる名前を入力します。名前が入っている場合は、そのまま使うか書き換えます。
  4. 「決定して入室」を1回押します。品物の一覧が表示されます。

ここを確認　参加者として入るときは「決定して入室」を使うと迷いません。大きな「入札者として参加」ボタンの連続タップは、主催者用の入口にもなっています。

品物がないとき　初回は品物が0件でも正常です。主催者の出品を待ちます。品物が届かない場合は8ページの確認表をご覧ください。

2 品物を選んで入札する

商品カードの「入札する」を押して詳細を開き、金額を確認してから入札します。

  1. 一覧で品物を選び、「入札する」を押して詳細画面を開きます。説明、状態、価格を確認します。
  2. 「次回最低入札」の金額を確認し、その金額以上の整数を入力します。例：現在1,000円、刻み100円なら、最初の入札は1,100円以上です。
  3. 金額欄の横にある「入札する」を1回押します。確認画面は出ません。金額をよく確認してから押してください。
  4. 入札履歴と最高額を確認します。通信に時間がかかる場合があるため、同じ操作をすぐに繰り返さず、他の参加者の表示も確認します。

入札前に知っておくこと　入札を取り消す操作はありません。終了済み、または終了時刻を過ぎた品物には入札できません。

補助ボタン　「質問する」は未実装です。質問は Delta Chat のチャットへ書き込みます。「ウォッチ」はその画面での目印です。閉じた後の保存や端末間共有を前提にしないでください。

3 主催者として入室する

出品や終了操作を行う方は、名前を入れてから主催者用の入口を開きます。

  1. 最初の「入札者登録」画面で、主催者として表示する名前を「お名前」に入力します。
  2. 大きな「入札者として参加」ボタンを、初期設定では約1.5秒以内に3回タップします。パソコンでは素早く3回クリックします。
  3. 「オークショニアモード」が表示されたら、パスワードを入力します。初期値は半角小文字の secret です。
  4. 「入室」を押します。「新規出品」が表示されれば主催者として入室できています。

開けないとき　タップがゆっくりだと連続操作として数えられません。一度手を止めてから、素早く3回やり直します。パスワードは大文字と小文字を区別します。

歯車の設定　主催者画面の歯車でタップ回数とパスワードを変更できます。この版の設定は、アプリを閉じた後も保存される仕組みではありません。再起動時は初期値を確認してください。

主催者用の入口について　このパスワードは画面の切り替え用です。参加者の不正な操作を防ぐ本人確認の仕組みではありません。信頼できる参加者同士で使い、主催者をチャットで共有してください。

4 出品してオークションを締める

出品時の条件を確認し、終了時には主催者が「締めて落札」を押します。

  1. 「新規出品」でタイトルと説明を入力します。説明には、状態、サイズ、受け渡し方法などを書きます。
  2. 画像を付ける場合は「＋」で選びます。最大4枚です。開始価格は0円以上、最低入札単位は1円以上の整数で指定します。
  3. 必要なら終了時間を指定し、「出品する」を押します。上部の送信待ちを確認し、参加者にも品物が表示されたか確認します。
  4. 終了する品物の入札履歴と最高額を確認して「締めて落札」を押します。確認画面は出ません。入札があれば最高入札者が落札者として表示され、入札がなければ落札者なしで終了します。

時刻を指定した場合　終了時刻を過ぎると入札できなくなりますが、落札者を確定するために主催者が「締めて落札」を押す必要があります。締める前に、各端末の入札履歴がそろっているか確認してください。

支払いと受け渡し　アプリには決済や配送の機能はありません。落札結果を確認した後、Delta Chat で相手と相談してください。品物の編集、削除、入札取り消し、終了の取り消し操作もありません。

5 バックアップを書き出す

新版へ移る前に、品物と入札履歴を JSON ファイルとして保存します。JSON はアプリが読み込むための保存用ファイルです。

  1. 画面最上部の「同期・データ引き継ぎ」を押して開きます。
  2. 送信待ちの表示がなくなり、「同期受付中 · v1.1.0」と表示されるまで、アプリを開いたまま待ちます。
  3. 「バックアップを書き出す」を押します。Delta Chat 側にファイル付きの送信画面や下書きが用意されます。
  4. Auction-House-backup-日付.json というファイルを確認して、保存先のチャットへ送信します。必要に応じて端末にも保存します。アプリのボタンを押しただけで保存が完了したと思わず、ファイルが残ったことを確認してください。

書き出すタイミング　新版へ移る直前と、オークション終了後に保存すると安心です。移行時は先に入札を止め、参加者の履歴がそろっていることを確認してください。

保存される内容　出品情報、画像、入札履歴、落札結果、送信待ち情報が対象です。入室中の役割、ウォッチ、主催者用パスワードなどの画面設定は引き継ぎ対象ではありません。参加者の名前や識別情報を含むため、共有先に注意してください。

6 新版へデータを引き継ぐ

新版は別のアプリとして開き、保存したバックアップを読み込みます。参加者全員で移行先をそろえてください。

  1. 旧版で入札を止め、6ページの手順でバックアップを保存します。移行作業は主催者1人がまとめて行います。
  2. 新しい .xdc を参加者のチャットへ送ります。全員に「以後はこの新しいメッセージのアプリを使う」と伝えます。
  3. 新版を開き、初回の履歴同期が終わってから「同期・データ引き継ぎ」を開きます。
  4. 「バックアップを読み込む」のファイル選択を押し、保存した .json ファイルを選びます。選ぶと読み込みと参加者への送信が始まります。
  5. 送信待ちがなくなるまで開いておき、出品・入札・落札結果を確認します。他の参加者も同じ新版を開き、内容がそろってから再開します。

読み込みの性質　既存データを消して入れ替える操作ではなく、データを追加してまとめる操作です。空の新版で読み込むと確認しやすくなります。読み込んだ内容は、その新版を共有する参加者にも送信されます。

元の v1.0.0 について　元の v1.0.0 にはバックアップ機能がありません。このファイル形式による引き継ぎは修正版 v1.1.0 から使えます。元の画面だけに残っている情報は閉じる前に記録し、修正版へ手作業で登録してください。失われた未保存データは復元できません。

7 困ったときの確認表

通信や操作で迷ったときは、次の順に確認してください。

困ったこと確認すること
ほかの人と品物が違う同じチャット内の、同じアプリのメッセージを開いているか確認します。旧版と新版、各自が別々に送ったアプリを混ぜないでください。
品物や入札が届かないネット接続と、チャットへ通常のメッセージを送れる状態かを確認します。アプリを開いたまま待ち、相手にも表示を確認してもらいます。
送信待ちが減らない画像付きの出品は複数回に分けて送られます。閉じずに待ちます。エラーが続く場合は表示内容を主催者に伝えます。
入札できない次回最低入札以上の整数か確認します。終了済み、または終了時刻を過ぎた品物には入札できません。
主催者画面に入れない名前を入力し、参加ボタンを素早く3回押します。初期パスワードは secret です。設定を変更した場合はその値を使います。
質問ボタンが使えない質問機能は未実装です。Delta Chat のチャットで質問してください。
バックアップを読み込めないこのアプリが書き出した .json か確認します。初回同期後に選びます。32MBを超えるファイルや非対応の形式は読み込めません。
締めた後の金額がおかしい参加者それぞれの入札履歴をチャットで確認します。画面上の送信完了だけでは、全員への到着までは分かりません。

同期表示の意味　「履歴を同期中…」は過去の更新の読み込み中、「送信待ち N 件」はホストへの送信待ちです。「同期受付中」はアプリが同期を受け付ける状態で、全端末に到着した保証ではありません。画面下部などの「リアルタイム」という文字だけで、同期完了を判断しないでください。

結果や入札をチャットへ知らせる　入札履歴などの「長押しで転送」とある行を長押しすると、転送の確認を開けます。「転送する」の後は、Delta Chat 側でも送信先と内容を確認してください。

確認範囲　画面と手順は修正版 v1.1.0 の実装および検証用ブラウザーで確認しました。Delta Chat 実機間での通信と端末ごとのファイル選択画面は未確認です。作成日 2026年10月17日。
